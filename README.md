# いとくぐり

画面を押している間は糸が上がり、離すと下がります。
壁にぶつからないように進んで、針の穴に糸を通していくゲームです。
通した本数が増えるほど、スピードが上がり、通路と針の穴がせまくなります。

- Galaxy Z Fold8 を閉じた状態（カバー画面）での縦持ち・片手プレイを前提に調整しています
- 画面の下は親指を置く場所で、ゲーム画面はその上に表示されます（どこを押しても操作できます）
- ブラウザだけで動きます（`index.html` を開くだけ）
- 操作: タップ長押し / マウス長押し / スペースキー・↑キー
- 音は最初オフです。右上のボタンでオンにできます
- ベスト記録はそのブラウザの中に保存されます
- アプリを切り替えると自動で一時停止します

## 調整用の数値

`index.html` の `<script>` 冒頭と「コースの生成」部分にまとまっています。

| 名前 | 内容 |
|---|---|
| `V0` / `VSTEP` / `VCAP` | 最初の速さ / 1本ごとに速くなる量 / 最高速度 |
| `ACC` / `VMAX` | 糸の上下の動きやすさ |
| `gapNow` | 通路の広さ（600 → 340） |
| `eyeNow` | 針の穴の大きさ（210 → 120） |
| `spacingNow` | 針と針の間隔（640 → 520） |
