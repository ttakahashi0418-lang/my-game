# かけぬけロード

自動で前に走り続けるキャラクターを左右移動とジャンプで操作し、障害物をよけながらゴールを目指すステージ制ランゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール不要）。

| 操作 | スマホ | PC |
| --- | --- | --- |
| レーン移動 | 左右にスワイプ | ← → / A・D |
| ジャンプ | 上にスワイプ | ↑ / W / スペース |
| 一時停止 | 右上の II ボタン | P / Esc |

- **石の壁**：跳べないので左右によける
- **倒木**：ジャンプで越える
- **落とし穴**：ジャンプで越えるか、穴のないレーンへ
- **シールド**：1回だけダメージを防ぐ
- **マグネット**：8秒間コインを引き寄せる

ハートは3つ。0になるとそのステージはやり直しです。
ゴールで★1、コイン6割以上で★+1、ノーダメージで★+1。

| 5 | 霧の森 | 850m | 15 m/s |
| 6 | 雪の峠 | 950m | 16 m/s |
| 7 | 灯りの夜道 | 1050m | 17 m/s |

ステージの中身は `index.html` 内の `STAGES`（距離・速さ・出てくる障害物の種類）と
`buildStage()`（障害物の並べ方）で決まっています。
