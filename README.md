# もちもちジャンプ

白いおもちを左右に動かして、足場をどこまでも登っていくジャンプゲームです。
足場にのると自動でジャンプします。下に落ちたらゲームオーバー。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール不要）。

- **スマホ / タブレット**：画面の左半分・右半分を押して移動
  - タイトル画面の「傾き操作」をONにすると、本体を傾けて動かせます（対応端末のみ）
- **パソコン**：← → キー（または A / D キー）で移動、Esc / P で一時停止
- 画面の端から出ると、反対側から出てきます

## 足場の種類

| 見た目 | 種類 | 動き |
| --- | --- | --- |
| きなこ色 | ふつうの足場 | 何度でものれる |
| 赤いバネつき | バネ | 大ジャンプ |
| 紫色（矢印つき） | 動く足場 | 左右に動く（約70mから） |
| ひびの入った茶色 | おせんべい | 1回のるとこわれる（約270mから） |

## エリア

登った高さで空の色が変わります。

- 0m〜 ふもと
- 300m〜 雲の上
- 800m〜 夜空
- 1500m〜 宇宙

ベスト記録はブラウザに保存されます。
