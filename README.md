# めぐり迷宮

ブラウザで遊べるローグライク・ダンジョンRPGです。地下50階を目指して潜り、5階ごとのボスと最深部のラスボスをたおします。
クリアすると、レベル・ステータス・持ち物を引き継いで「次の周回」を地下1階から遊べます（周回ごとに敵が強くなり、終わりはありません）。

## 遊び方
- `index.html` をブラウザで開くだけで遊べます（スマホ・PC 両対応、セーブは自動）。
- スマホ：画面下の方向ボタンで移動（長押しで歩き続ける）、右のボタンで攻撃・道具など。
- PC：矢印キー / テンキー / `hjklyubn` で移動、`.` 足踏み、`f` 攻撃、`i` 道具、`g` 足元、`m` 地図。

## スマホのホーム画面に置く
GitHub Pages で公開すると、`https://ttakahashi0418-lang.github.io/my-game/` で遊べます。
Chrome でこのURLを開き、メニュー（︙）→「ホーム画面に追加」（または「アプリをインストール」）でアプリのように起動できます。
一度開けば、電波がないところでも遊べます。

## ファイル構成
- `src/game.html` … ゲーム本体（編集するのはこちら）
- `build.sh` … `src/game.html` を包んで `index.html` を作るスクリプト
- `index.html` … ビルド結果（そのまま開いて遊べる）
- `manifest.webmanifest`・`sw.js`・`icons/` … ホーム画面に追加して使うための設定・オフライン対応・アイコン

## 主な仕様
- フロアは毎回ランダム生成（部屋と通路）。ターン制、8方向移動、角をはさんだ斜め移動は不可。
- おなか（満腹度）、レベルアップ、武器・盾と強化値、草・巻物・杖・投げ物、罠。
- 5・10・15…45階にボス、50階にラスボス。ボスをたおすと階段が現れる。
- 力尽きると、最後のチェックポイント（地下1・6・11…階に着いた時点）からやり直し。
- 効果音・BGMは Web Audio でその場で合成（音声ファイルなし）。メニューからオン・オフ可能。
- 階段に乗ると「降りますか？」の確認が出る。
- 周回：敵の強さは「階数＋35×(周回−1)」の深さで決まる。周回が進むと深い階の敵が浅い階にも出現し、★つきの強化個体も出る。より強い装備も出るようになる。
